## Language

The key words **MUST**, **MUST NOT**, **SHOULD**, **SHOULD NOT** and **MAY** express requirements for the proposed
SDK or a proposed contract. They do not create a claim that Kumwe core already implements the requirement. Current
core behavior is always labeled **Observed**; a desired core addition is **Required** or **Proposed**.
